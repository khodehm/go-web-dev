# Getting started 
> you should have go - postgresql installed 
> Create `bookstore` data base with  `bookstoremanager` role on it to connect
> replace the connection string in `config/db.go` with your user and password "postgresql://bookstoremanager:password@localhost/bookstore?sslmode=disable"
> After you installed postgres in your machine run the executeable files in `build/` directory
> Now open it your browser 
```
 http://localhost:9090/

```
